# Addendum (v2.5): Top-aligned growth removes the ln over-depth curriculum limit

**Status**: Follow-on to the v2.4 note (`basin_selection_warmstart_note.md`).
Data: `results/basin_warmstart_v2.5_unbalanced.csv` (120 rows, snapshot in
`results/v2.5_unbalanced_snapshot/`).

## The v2.4 limitation

The v2.4 note documented a structural limit: curriculum for ln at
over-representational depth (d=5) could not use `grow_from_shallow`, because a
balanced EML gate cannot act as an identity forwarder — there is no a,b from
{1,x,f} with exp(a) − ln(b) = f for arbitrary f. Extending a valid shallow ln
solution upward by 'f'-chaining therefore embeds exp(ln(x)) = x before any
training. The v2.4 driver delegated ln over-depth curriculum to the direct
`initialize_to_target('ln')` init, and the note flagged unbalanced/RPN-style
trees as the path forward.

## The fix: embed top-aligned, let extra capacity dangle below

The useful property of unbalanced/RPN trees is not the asymmetry itself but
that **unused branches can dangle**. Balanced trees already provide this —
below the embedded solution. Because both trees are balanced, shallow level
*si* and deep level *si + Δ* (Δ = extra levels) have identical gate counts,
and child 'f' references (positions 2·gi, 2·gi+1) line up exactly. So
`grow_from_shallow` (v2.5) copies the trained shallow solution into the **top**
Δ-shifted levels: the root stays the root, the shallow's bottom gates (which
only select from {1,x}, direct injection) ignore the deep tree's new bottom
levels entirely, and those become constant-biased dangling extra capacity —
exactly the inactive parallel branches of Odrzywolek's RPN construction,
realized inside the balanced architecture. The embedded value is preserved
exactly (smoke test: embedded form `eml(1,eml(eml(1,x),1))`, max value error
2.4e-7 after snap; `reanneal_extra_capacity` leaves the block intact via the
per-level width metadata, with the dangling bottom marked width 0).

## Results (20 seeds, 2000 epochs, noise 0.4, reanneal 200)

| cell    | blind | warm | curriculum |
|---------|-------|------|------------|
| ln d=5  | 5/20 (25%) | 20/20 (100%) | **20/20 (100%)** (was: delegated in v2.4) |
| exp d=3 | 7/20 (35%) | 20/20 (100%) | 20/20 (100%) (unchanged) |

All ln valid forms are exactly `eml(1,eml(eml(1,x),1))`; all exp forms
`eml(x,1)`. Blind/warm rates match v2.4_postfix run-for-run (identical
deterministic seeding), confirming no regression from the code change.

**Fallback audit**: the driver falls back to direct init when the shallow
pre-training is not valid, and the CSV alone cannot distinguish the two paths.
Replaying the shallow phase for all 20 effective curriculum seeds showed all
20 shallow d=4 pre-trainings valid — every curriculum row used the real
grow-from-shallow path.

## Implication

Curriculum for ln at over-representational depth is now a *real* curriculum
(train shallow at representational depth, grow, re-anneal extra capacity,
fine-tune) with 100% valid recovery — the same status exp already had. The
"narrow structural limit" qualifier in the v2.4 note applies only to
*upward/bottom-aligned* extension; top-aligned growth sidesteps it without
architectural changes. Remaining genuinely open: targets whose shallow
solutions are not reliably recoverable warm (none in the current set), and
true unbalanced/DAG sharing for *reducing* required depth (still future work).
